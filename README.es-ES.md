

# Colección de Instrucciones Personalizadas para Claude

¡Bienvenido a mi colección de instrucciones personalizadas para Claude! Este repositorio contiene instrucciones especializadas que he desarrollado para usar con Claude Desktop. Comparto estas instrucciones para que otras personas también puedan beneficiarse de ellas.

## ¿Qué hay en este repositorio?

Este repositorio contiene instrucciones personalizadas que pueden usarse con Claude Desktop para mejorar sus capacidades en tareas y flujos de trabajo específicos. Cada archivo de instrucciones está diseñado para ser copiado y pegado directamente en los Proyectos de Claude.

## Requisitos

Para usar estas instrucciones, necesitarás:

1. **Aplicación Claude Desktop** - Estas instrucciones están diseñadas específicamente para usarse con la versión de escritorio de Claude.
2. **Servidores de Model Context Protocol (MCP)** - Muchas instrucciones requieren que se ejecuten servidores MCP específicos. Cada archivo de instrucciones especifica qué MCP son necesarios.

## Instrucciones Disponibles

- [News First Source](./News-First-Source.md) - Un protocolo para determinar la fuente publicada más temprana de una noticia utilizando Claude y servidores MCP.
- [Deepest Research](./Deepest-Research.md) - Un protocolo que transforma a Claude en un asistente de investigación metódico que realiza investigaciones exhaustivas a través de ciclos de investigación sistemáticos.
- [MCP Inspector](./MCP-Inspector.md) - Un protocolo que transforma a Claude en un sistema integral de evaluación de servidores MCP que analiza automáticamente repositorios de GitHub que contienen servidores MCP en busca de riesgos de seguridad, privacidad y fiabilidad.
- [Ultra Search](./Ultra-Search.md) - Un protocolo que maximiza las capacidades de investigación y recopilación de información de Claude Desktop al activar automáticamente y combinar inteligentemente múltiples herramientas MCP.
- [PRD Generator](./PRD-Generator.md) - Un protocolo que transforma a Claude en un creador integral de Documentos de Requisitos de Producto que ayuda a planificar y documentar productos de manera efectiva a través de conversaciones estructuradas.

## Cómo Usar Estas Instrucciones

1. Node.js debe estar instalado en tu sistema. Si no lo está, instala la última versión desde [este enlace](https://nodejs.org/en/download)
2. Instala la aplicación Claude Desktop si aún no lo has hecho
3. Configura los servidores MCP requeridos mencionados en la instrucción específica
4. Crea un nuevo Proyecto de Claude para el propósito específico (por ejemplo, un proyecto "Buscador de Fuentes de Noticias")
5. Abre el archivo de instrucciones que deseas usar en este repositorio
6. Copia el contenido desde la sección del bloque de código en el archivo de instrucciones
7. Pégalo en la sección de instrucciones personalizadas del Proyecto de Claude
8. Inicia una conversación dentro de ese proyecto haciendo referencia a la instrucción

Crear Proyectos de Claude separados para cada tipo de instrucción te permite organizar tu trabajo y mantener diferentes versiones especializadas de Claude para distintas tareas.
